「매부리코」는 더 확정적입니다. canonical_face_model.obj 의 실제 좌표에서 코끝(LM1)은 그 아래 점(LM2)보다 항상 위에 있으므로 ai[1].y − ai[2].y 는 언제나 음수입니다. 60,000건 표본에서 0건 발생했습니다.

점수도 같은 문제를 겪었습니다 — 입 점수는 고유값이 1개(86점, 100%), 눈 점수는 2개(90점이 98.6%), 얼굴형 점수는 상수 네 개 중 82점이 97.7%였습니다.

아직 사실이 아닌 것

고친 범위를 정확히 그어 둡니다. 이 선을 넘어서 인용하면 다음 세션이 잘못된 전제 위에서 일하게 됩니다.

관상 참조분포는 합성 유래(TIER-C)입니다.

「각진형」은 이제 “하악각폭이 상위 38%”라는 뜻이지 “실제로 각진 얼굴”이 아닙니다. 다양성은 해결됐지만 절대적 의미는 아직 보정되지 않았습니다. 실사진 200~500장의 계측값이 필요합니다.

그런데 얼굴 계측값은 생체인식정보입니다 — 손금 트랙에서 이미 확정한 것과 같은 문제입니다. 라이선스(CC0 등)는 동의가 아니고, 공개 얼굴 데이터셋에도 상업 판정용 동의는 없습니다. 손금 원격수집 패킷과 같은 동의 절차로 모으거나, TIER-C 임을 화면에 명시해야 합니다.

LLM 출력 문자열 자체의 유사도는 측정하지 않았습니다.

이번에 고친 것은 프롬프트 입력의 다양성입니다. 모델이 그 씨앗을 실제 문체에 반영하는지는 type 별 서로 다른 입력 30건 × 3회 호출 후 임베딩 코사인 유사도를 재는 별도 실험이 필요합니다. 참고로 temperature·top_p·seed·캐싱이 전부 미설정이라 문자열 자체는 호출마다 다릅니다 — 「비슷함」은 캐시 탓이 아닙니다.
