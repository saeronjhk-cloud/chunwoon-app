# 1. ★★Tier 개념 — 이 문서의 뼈대

| | **Tier-A (연막 시험)** | **Tier-B (판정)** |
|---|---|---|
| **답하는 질문** | 「추론이 도는가 · 입력 해상도는 · 출력이 선처럼 생겼는가」 | 「★**합격인가 불합격인가**」 |
| 출처 | 공개 데이터셋 · 라이선스 명확한 것 | ★**동의 받은 실제 사진** |
| 라벨 | 없어도 됨 (있으면 육안 대조에 유용) | ★**라벨규칙 v1 대로 직접 라벨** |
| 분량 | **10~50장**이면 충분 | **40~50장** (20~25명) |
| 다양성 요구 | 낮음 | ★**높음** (피부색·나이·손 크기) |
| ★**지표를 낼 수 있는가** | ★★**낼 수는 있으나 「판정」이라 부를 수 없습니다** | ★**여기서만 판정합니다** |

## 1-1. ★★왜 Tier-A 로 판정하면 안 되는가 (3가지)

```
★① 선택 편향 — 공개 데이터셋과 손금 사이트는 「선이 잘 보이는 손」이 과대표집됩니다.
     거기서 mIoU 0.7 이 나와도 ★「우리 사용자가 폰으로 대충 찍은 손」을 답하지 못합니다.

★② 도메인 격차 — 팜프린트 인식용 데이터는 거의 전부 ★접촉식/장치식 + 균일조명 +
     ROI 크롭입니다. 실제 폰카메라와 촬영 조건이 다릅니다 (§4-2 표).

★③ 라벨 정의가 다릅니다 — Roboflow 라벨은 ★Line1~Line4 (★4선)이고
     우리는 ★3선(RLC/PTC/DTC)입니다. 경계 정의도 우리 라벨규칙 §3 과 다릅니다.
     ⟹ ★그 라벨을 GT 로 쓰면 「남의 기준으로 우리 모델을 채점」하는 것이 됩니다.
```

★★**①은 정확히 2026-05 의 재현입니다.** 그때는 폴백이 숫자를 만들었고, 이번엔 **데이터 선택**이 만듭니다.
 ⟹ 라벨규칙 §7 「재개하지 않을 조건」이 무의미해집니다 — **기준을 통과하도록 데이터를 고르는 셈**이라서.
